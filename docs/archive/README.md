# Archived documentation

These files are **historical snapshots** from earlier in development (sprint
summaries, per-task implementation write-ups, and point-in-time status reports).
They are kept for reference but are **not maintained** and may not reflect the
current state of the code.

Several of them (notably `FEATURE_001_COMPLETE.md`) declare the project
"complete" with a passing test suite — that was inaccurate by the time later
fixes landed. **Do not treat anything in this folder as current.**

For the current state of the project, see:

- [`../../README.md`](../../README.md) — product overview and setup
- [`../PROJECT_STATUS.md`](../PROJECT_STATUS.md) — current build/test status and known issues
